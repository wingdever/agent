# QQ 社区群聊机器人

本枝记录 QQ 社区群聊机器人的产品定位、知识沉淀、用户画像与运行边界。

## 范围

- **群知识**：外部领域资料底座 + 群内验证卡片。
- **用户画像**：字段级 claim，按群隔离，可撤回、可过期。
- **运行边界**：官方 QQ 机器人接入、群消息权限、限流、引用与审核。

## 约定

- 外部资料只读、版本化；群卡片经管理员验证后生效。
- LLM 生成内容不进入正式检索索引，只用于提纲、问题与评测。
- 画像只存可观察行为与明确自述，不存敏感推断和负面评价。
- RAG 平台只提供检索与生成能力；QQ 网关、引用格式、限流和审核留在本项目。
