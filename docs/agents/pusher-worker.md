# pusher–worker 结对

## 范围

本文件是**无人值守任务周期**的一个候选方案（类别与判据见 `docs/agents/unattended.md`）：规划方（pusher，主会话）把目标拆成任务块，执行方（worker，子代理会话）逐块执行，规划方逐块验收并派下一块，整个周期内不需要人类输入。

它不是"长任务"的通用做法，也不规定必须沿用项目里已有的组件。本文件只描述这个方案自身的结构与判据；**计划载体、目标表示、开轮驱动在实现前要重新调查和讨论**（§6），当前只列出候选与选择判据。

## 1 角色

| 角色 | 持有 | 不持有 |
|---|---|---|
| pusher | 计划写权、验收权、周期终止判断；规划上下文 | 块内执行 |
| worker | 块内执行；自己的会话历史 | 计划写权、完成判定 |
| 驱动 | 周期内的排轮与重试（可复用通用开轮来源） | 完成判定 |

pusher 是主会话，worker 是它派出的子代理会话；一个周期只对一个 worker，串行执行。

## 2 周期循环

1. pusher 把目标拆成任务块，写入计划载体；
2. pusher 派一块给 worker，worker 在自己的会话里执行并汇报；
3. pusher 验收（自行核对产出、运行测试），判定完成或退回；
4. 重复 2–3，直到 §5 的截止条件；
5. 周期结束，交回人类回顾。

周期内的每一轮由驱动发起：驱动判断"该继续"后让 pusher 进入下一轮；pusher 之外没有人介入开轮。

## 3 候选组件

以下是可选的零件，没有默认选择；实现前按 §6 的判据重新选型。

### 3.1 开轮驱动

- **通用轮次来源**：周期驱动登记为 `turnSource`（`docs/agents/lifecycle.md`），自己判断何时开轮；
- **goal 的续轮**：若周期显式以 goal 作为目标表示，可由 goal 的驱动器承担开轮；此时周期不设自己的驱动；
- **schedule**：只在有固定节奏的场景下考虑，作为兜底而不是主驱动。

### 3.2 目标与完成表示

- **goal**：持久目标 + 阶段机 + 完成判定；
- **任务清单状态**：全部块完成即完成；
- **周期自有进度事实**：周期自己记录块与验收结果。

### 3.3 计划载体

- **todo_write**：单会话内的清单，改派与依赖能力弱；
- **team task**：带依赖、认领、CAS 的共享任务板；
- **周期自有任务表**：周期自己建表，只服务这一个方案。

### 3.4 执行者

- **subagent**：有独立持久会话，可保留自己的历史；
- **fork 子代理**：从规划上下文分叉，适合块与块强相关的场景；
- **同一会话内执行**：不派子代理，由 pusher 自己在同一上下文里做；规划上下文与执行细节不再隔离。

## 4 选择判据

选型时按下列问题逐项回答，答案不一致就说明组件选错了：

- **谁有权判完成**：执行方自述能否被当作完成事实？不能，就需要一个能独立复核的完成表示。
- **计划谁能写**：执行方需要改计划吗？需要的话，计划载体必须支持"提议—采纳"而不是直接改写。
- **状态跨重启怎么办**：周期继续、暂停还是结束？选定的载体要能支持这个答案。
- **开轮谁负责**：周期驱动、goal 驱动器还是其它；一个周期只能有一个开轮者，多个来源同时存在时会争抢。
- **执行者上下文如何累积**：块之间是否共享上下文；隔离需求决定选子代理还是同会话。
- **成本与可观察性**：轮次与花费在哪里看；周期结束后要留哪些过程记录。

## 5 截止与失败自愈

截止与自愈必须满足 `docs/agents/unattended.md` §1.4、§1.5 的判据。本方案的倾向（实现时按选择结果确认）：

- **可判定截止**：周期轮次上限、时间窗；
- **语义截止**：计划耗尽、连续若干轮任务状态无变化；
- **自愈**：执行失败先由驱动重试；重试耗尽换执行者重做该块；只有"目标不可达、计划无法补拆、预算用尽"这三类才停下等人。

边界情况：无人在场时无法审批，需要审批的动作必须在周期开始前一次批准，或在计划里排除。

## 6 实现前的开口

以下是本方案尚未定下、实现前必须重新调查并讨论的问题：

1. 开轮驱动选哪个零件（通用来源 / goal 续轮）；
2. 目标与完成表示选哪个零件；
3. 计划载体选哪个零件；
4. 执行者选哪个零件；
5. 周期状态存在哪里、跨重启时继续还是结束；
6. 人类介入的形态：发消息、暂停、打断分别落到哪些接口。

## 7 与其它能力的关系

- **goal**：可选引用。goal 是单会话的持久目标与自动续轮，按自身语义设计与实现，不为本方案做任何预留；本方案借用时只借用它的接口。
- **todo / team task / schedule / subagents**：可选引用，按 §4 判据选型。
- **job**：块内的长命令可以交给 job 或用户任务，不改变周期结构。
